# Memory Archive

Archived memory files. Old MEMORY.md chronology and DREAMS.md entries are moved here when they get too large.

## Why Archive?

Keeping MEMORY.md and DREAMS.md small (~2-3KB each) improves prompt cache hit rate. Old content is preserved here for reference.

## What Goes Here

- `MEMORY-YYYY-MM-DD-full.md` — Archived MEMORY.md snapshots
- `dreams-YYYY-MM-DD-full.md` — Archived DREAMS.md snapshots
- Old daily memory files (optional)
